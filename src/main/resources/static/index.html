reCAPTCHA - Policy-Based Challenge

Esta aplicação mostra o padrão WEB recomendado para uso de chave com desafio baseado em política: gere o token no navegador, crie o assessment no backend, valide a ação e deixe o backend decidir se a solicitação é permitida.

  • A chave reCAPTCHA (site key) é pública e pode ficar exposta.
  • A chave API (secret key) deve ficar no backend de forma restrita.
  • O backend deve criar o assessment dentro de 2 minutos (expiração do token).
